# Grill Me Docs

Run the `/grilling` skill to interview the user about every aspect of the plan — walking each branch of the design tree, resolving dependencies one-by-one.

While grilling, run the `/domain-modeling` skill to keep the domain model current as decisions crystallise — challenge terms against the glossary, sharpen fuzzy language, update `CONTEXT.md` inline, and offer ADRs sparingly.
